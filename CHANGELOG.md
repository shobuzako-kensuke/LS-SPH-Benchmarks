# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [0.1.0](https://github.com/shobuzako-kensuke/LS-SPH-Benchmarks/releases/tag/v0.1.0) - 2026-04-20

### Added

- `materials/` directory for project documentation.
- `source/` directory for Fortran source code.
- `Makefile` for compiling the Fortran source code.
- `config.h` for setting up the simulation problem and input parameters.
- `initialize.py` for repository initialization.
- `analysis_main.py` for analyzing simulation results.

### Changed

- Added comments to `.gitignore`.
- Updated release tag in `CITATION.cff`.
- Updated contents of `CONTRIBUTORS.md`.
- Updated `README.md` and `README_ja.md`.

### Removed
- `input.f90` (replaced by `config.h`).
